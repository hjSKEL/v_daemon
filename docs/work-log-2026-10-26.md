# 작업 내역 (2026-10-26)

## 기존 변경 확인과 전달

- 스케줄 충전 시간을 시·분·초로 입력하고 API 요청 시 초로 합산한다. 합계 1초~24시간, 분·초 0~59 제한과 커넥터별 입력 보존 테스트를 포함한다.
- 등록 충전기의 커넥터 누적 계량값을 읽기 전용 DB 조회 API로 가져온다. 선택 커넥터의 CA_ELE_NRG(kWh)를 Wh로 환산해 시작 계량값에 입력하며 다시 조회할 수 있다.
- 직접 입력한 값과 커넥터별 초안을 보존하고, 이전 충전기·커넥터의 늦은 조회 응답이 현재 입력을 덮어쓰지 않도록 한다. 누락·음수·잘못된 값·정수 범위 초과 또는 조회 실패는 안내를 표시하고, 빈 값을 0으로 전송하지 않는다.
- README와 Java HTTP 테스트·JavaScript 화면 모의 테스트를 함께 반영한다. 이번 전달 과정에서 기능 코드는 추가 수정하지 않았다.
