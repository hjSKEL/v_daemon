## localcsms SP 변경 대응

- origin/main을 확인했으며 `e9c031f`로 이미 최신 상태였다.
- localcsms `91f6de1`은 SP 실행 인자를 제거하고 충전기별 `TB_CHCS001.SP`로 인증 방식을 결정한다. SP2는 TLS + Basic Auth, SP3는 클라이언트 인증서를 사용한다. SP0/SP1 평문 연결은 새 데몬에서 지원하지 않는다.
- `start-local-daemon.ps1`에서 기존 SP1 인자 `1`을 제거해 `127.0.0.1 8900`을 전달하도록 수정했다. 기존 README와 properties의 SP1 보조 도구 설명은 과거 동작이며 새 데몬에는 적용되지 않는다.
- 기존 Config의 인증서 로드와 Transport의 Basic Auth 헤더 전송은 새 서버 인증 방식과 호환된다. 통신 코드는 변경하지 않았다. SP2 시험은 해당 충전기의 DB 설정을 2로 지정하고 WSS 접속과 CS_PWD 비밀번호를 사용해야 한다.
- PowerShell 구문 분석과 `-DryRun`을 확인했다. 실행 정책 때문에 DryRun은 별도 PowerShell 프로세스에 `-ExecutionPolicy Bypass`를 지정했다. 시스템 실행 정책은 변경하지 않았다.
